# 말랑이 — LCD 1602 하트비트 캐릭터

Arduino UNO + I2C LCD 1602의 첫째 줄 첫 글자 칸(0,0)에 Custom Character로 만든 젤리 캐릭터 '말랑이'가 점프하며 아두이노가 동작 중임을 표시합니다.

- 웹 페이지(연결도·스케치·데모 사진·설명·고찰): https://kangminpk12.github.io/mallangi-lcd-heartbeat/
- 스케치: [`mallangi_heartbeat.ino`](mallangi_heartbeat.ino)
- 연결: GND→GND, VCC→5V, SDA→A4, SCL→A5 (I2C 주소 0x27)
